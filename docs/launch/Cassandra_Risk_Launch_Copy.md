## LinkedIn Launch Post - Primary

Today I launched my first commercial API: **Cassandra-Risk**.

It started as a research question:

How do you build a forward-looking macro-risk overlay that reacts to
event-implied fragility before realized volatility fully reveals the damage?

That question turned into a three-paper research program, a public GitHub
repository, a governed live signal engine, and now a paid API listed on
RapidAPI.

**Cassandra-Risk** is a governed macro-fragility signal API that converts
prediction-market event probabilities into:

- a live Regime Stress Index (RSI)
- governed event-family risk snapshots
- a transparent, auditable signal registry

The product is backed by:

- **Paper 1**  
  *Beyond Value-at-Risk: Quantifying Regime Fragility via Prediction Market Event Forecasting*  
  DOI: 10.13140/RG.2.2.21272.05124

- **Paper 2**  
  *Cassandra-Risk Paper 2: Beyond the Backtest - Expansion, Calibration, and the Boundary Conditions of Forecast-Based Risk Overlays*  
  DOI: 10.13140/RG.2.2.17209.12644

- **Paper 3**  
  *Cassandra-Risk Paper 3: Cross-Platform Prediction Market Ensembles and Governed Signal Infrastructure*  
  DOI: 10.13140/RG.2.2.22910.75848

What is live today:

- public RapidAPI listing
- live Railway deployment
- governed signal registry
- live RSI endpoint
- event-family snapshots
- source-status monitoring
- free trial tier and Pro plan

This is the first time the full Cassandra chain exists in one place:

research -> code -> governance -> deployment -> monetization
